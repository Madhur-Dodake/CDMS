# CDMS

Court / Case Data Management System (CDMS)

## Overview
A web-based management system designed to streamline case tracking, record keeping, and workflow automation.

## Repository & Branch Workflow
- **`main`**: Protected, stable branch. Only receives merges from `dev` at the conclusion of completed, verified milestones/phases.
- **`dev`**: Default active development branch. All day-to-day work, feature integrations, and developmental commits happen here.
